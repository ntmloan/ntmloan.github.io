月次一覧または **勤怠情報の詳細** から休暇を申請できます。勤務日の行から開始すると時刻と理由がフォームに引き継がれます。詳細からの方法は休日を含むすべての日付で利用できます。

## 始める前に

- **自分の勤怠** にアクセスでき、会社で勤怠が有効であること。
- シフトに有効な申請定義と連動するLeaveステータスがあること。
- 休暇の日付、時間帯、理由、フォームの必須情報を用意すること。
- **作業時間の目安:** 約3分。承認待ち時間は別です。

**Leave** は表示名の例です。会社によって異なる名前の場合があります。

## 推奨: 月次一覧の行から開始する

勤務シフトの勤務日に使用します。

1. **自分の勤怠** を開きます。
2. シフトと月を選択します。
3. 休暇を申請する日付を探します。例: 5月4日。

**結果:** 行に **変更後の時刻** と **理由** の入力欄があります。

![休暇を申請する勤務日](/images/attendance/request-leave-in-table-start.png)

4. 休暇の開始・終了時刻を入力します。全日なら例として `08:30–17:30`。
5. 理由を入力します。例: `私用のため`。
6. 操作列の三点メニューを開きます。
7. Leave申請に連動するステータスを選択します。

**結果:** 選択した日付の申請作成画面が開きます。

![時間と理由を入力してLeaveを選択](/images/attendance/request-leave-in-table-fill.png)

## 入力済みのフォームを完成させる

日付、開始・終了時刻、理由、自動生成された件名が引き継がれます。

![引き継がれた入力値](/images/attendance/request-leave-in-table-application.png)

1. 引き継がれた値を確認します。
2. 休暇種別や不在区分など、残りの必須項目を入力します。
3. **次** を選択します。
4. 承認ルートを確認し、通常の[申請作成手順](/ja/docs/applications/create-application)で送信します。

**結果:** 保留中の行に稲妻アイコンが表示されます。

![保留中の申請アイコン](/images/attendance/example-after-apply-table.png)

## 別の方法: 日付の詳細から開始する

勤務日・休日のどちらでも利用できます。勤務日以外では行から時刻を引き継げないため、フォームで正しい時間帯を入力してください。

1. **自分の勤怠** の日付を選択します。
2. **勤怠情報の詳細** で **申請を作成** を選択します。
3. **申請補足** でLeaveのステータスを選択します。

**結果:** 選択した日付の申請作成画面が開きます。

![詳細からLeaveを選択](/images/attendance/example-leave-apply-application.png)

4. 開始・終了時刻を入力または確認します。
5. 残りの項目を入力します。
6. 承認ルートを確認して送信します。

**結果:** 詳細に **保留中** のLeave記録が追加され、一覧に稲妻が表示されます。

![保留中のLeave記録](/images/attendance/example-leave-after-apply.png)

## 承認後

元の記録は保持され、承認済みの休暇記録が追加されます。月次ラベルは優先順位で再計算されます。

### 全日休暇

元の状態が **出勤なし** で、休暇がシフト全体をカバーしている場合は、Leaveが月次ラベルとして表示されることがあります。

![承認後の全日休暇](/images/attendance/example-leave-after-approve-table.png)

### 半日休暇

残りの時間に勤務した元の記録が **遅刻** または **早退** の場合、それらがLeaveより優先されるため月次ラベルは遅刻・早退のままです。承認済みの半日休暇は詳細に保持されています。

## 申請を追跡する

日付の詳細でLeave記録のリンクを選ぶか、[本人の申請一覧](/ja/docs/applications/my-applications)を開きます。

## トラブルシューティング

### Leaveを選択できない

会社管理者にシフトのLeaveステータスと申請定義を確認してもらってください。

### 行で時刻・理由を入力できない

勤務日以外や未来の日付では入力できません。三点メニューまたは日付の詳細から申請を開き、フォームで入力してください。

### 送信後も出勤なしと表示される

保留中または却下済みの可能性があります。承認状態を確認してください。

### 承認済みの半日休暇でも遅刻・早退になる

表示優先順位による動作です。詳細で承認済みのLeave記録を確認してください。

詳細には、その日の元の打刻と申請から作成された記録がすべて保存されています。申請は元のデータを削除・置換しません。

## 始める前に

ログインして **自分の勤怠** にアクセスできること、会社で勤怠が有効であること、対象の日付のシフトと月が必要です。

## 詳細を開く

1. **自分の勤怠** を開きます。
2. シフトと月を選択します。
3. 一覧の日付を選択します。

**結果:** **勤怠情報の詳細** に、その日のすべての記録が表示されます。

![日付を選択](/images/attendance/move-to-detail-records.png)

![元の記録と修正記録](/images/attendance/record-detail.png)

## 履歴を読む

| 項目 | 意味 |
| --- | --- |
| 番号 | 記録の順番 |
| 時間 | 記録された出退勤時刻 |
| ステータス | 記録の状態。リンクアイコンから申請を開ける |
| 記録者 | 作成した人または元のデータソース |
| 承認ステータス | 保留中、承認済み、却下済み |
| 追加（承認） | 追加の承認情報がある場合に表示 |

該当する情報がない場合はダッシュが表示されます。例えば元の `08:17–12:18` の早退記録と、修正後の `08:17–17:30` のRegularized記録は両方保持されます。[優先順位](/ja/docs/company-administration/attendance/status)で月次ラベルが決まります。

## 申請を開く・作成する

ステータス横のリンクを選択すると、新しいタブで申請内容、承認ルート、現在の状態を確認できます。

**申請を作成** を選択すると、対象日付の **申請補足** が開きます。利用可能な種類とフィールドは会社の設定によって異なります。

## 権限

一般ユーザーと会社管理者は本人の明細と申請を確認できます。自分の勤怠では他の社員の記録を表示できません。

## トラブルシューティング

### 申請リンクがない

元の打刻など、申請に連動しない記録にはリンクがありません。記録者と承認ステータスを確認してください。

### 月次ラベルと明細のラベルが異なる

複数の記録から優先順位で1つが選択されています。詳細ですべてを確認してください。

### 適切な申請を選べない

会社管理者にテンプレートのインストールまたは連動ステータスの設定を依頼してください。

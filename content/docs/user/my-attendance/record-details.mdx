Attendance Record Details preserves every record associated with a date instead of replacing the original attendance data.

## Before you start

- **Required role:** Any signed-in user with access to My Attendance
- **Required feature:** Attendance must be enabled
- **You'll need:** A Work Shift and month containing the date you want to inspect

## How Attendance Records Are Stored

Original attendance records are read-only source records captured by an attendance device or another attendance source, such as a mobile attendance app in the future.

Submitting an attendance application does not overwrite or delete the original source record. Workflow adds an application-generated entry to the same date, so the source and application information remain available in the history.

The application-generated record may change the status displayed in the monthly table. When multiple records apply to the same date, Workflow selects the displayed status using the [attendance status priority rules](/en/docs/company-administration/attendance/status#status-priority). Priority affects the displayed result only; it does not modify the underlying records.

## Open Attendance Record Details

Select a date in the monthly table to open **Detail Attendance Information** for that day.

**Expected result:** The dialog displays every source and application-generated record for the selected date.

![Select a date to open its attendance details](/images/attendance/move-to-detail-records.png)

The dialog shows every original and application-generated record associated with the selected date.

![Original and correction records in Attendance Details](/images/attendance/record-detail.png)

| Column | Description |
| --- | --- |
| **No** | The sequence number of the record for the selected date. |
| **Time** | The check-in and check-out time stored in that record. |
| **Status** | The attendance status assigned to the record. For an application-generated record, select the link icon beside the status to open the referenced application. |
| **Record by** | The person or source that created the attendance record. |
| **Approval status** | The current approval state of the linked application, such as **Pending**, **Approved**, or **Rejected**. A dash indicates that the record is not waiting on an application approval. |
| **Additional (approval)** | Additional approval information associated with the record, when available. A dash indicates that no additional information applies. |

In the example, the first row is the original **08:17–12:18 Early** record. The second row is the **08:17–17:30 Regularized** correction record linked to an application. Both records remain available so the attendance history is preserved.

## Related Applications

The link icon beside an application-based status opens the referenced application. Use it to review the submitted information, approval route, and current approval state.

The **Create Application** action starts a new application for the selected attendance context. The available application types and fields depend on the Application Definitions configured by the company.

## Troubleshooting

### The application link is not displayed

**Why this happens:** The row is a source record or is not linked to an application.

**How to fix it:** Check **Record by** and **Approval status**. Only application-generated rows can open a related application.

### The monthly status differs from one row in the dialog

**Why this happens:** Several records apply to the date and display priority selects one result for the monthly table.

**How to fix it:** Review every row, then see [status priority](/en/docs/company-administration/attendance/status#status-priority).

### Create Application has no suitable option

**Why this happens:** Your company has not configured an application-based status for this Work Shift.

**How to fix it:** Ask a Company Admin to install an Attendance Application Template or configure a custom attendance status.

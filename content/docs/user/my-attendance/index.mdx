**My Attendance** is a standalone employee self-service page for reviewing your own attendance and starting attendance-related actions.

The page is available to both Standard Users and Company Admins. Regardless of your role, it only displays the attendance records of the account currently signed in.

## Before you start

- **Required role:** Standard User or Company Admin
- **Required feature:** Attendance must be enabled for your company
- **You'll need:** At least one Work Shift created by a Company Admin

---

## Access My Attendance

Select **My Attendance** from the sidebar.

**Expected result:** Workflow opens your attendance using the default Work Shift. If no Work Shift is default, it opens the first available Work Shift.

## What You Can Do

From My Attendance, you can:

- View your attendance records for the selected month.
- Switch between the company's active Work Shifts.
- Navigate to another month and filter records by attendance status.
- Review your recorded check-in time, check-out time, and current status.
- Correct one or multiple attendance dates.
- Request leave or overtime through the company's configured applications.
- Open the complete record history for a date.

## Switch Work Shift

The page header shows the currently selected Work Shift, including its name, working days, working hours, and break time.

Use the Work Shift selector on the right side of the header to switch to another active Work Shift. The attendance records are then displayed and evaluated against the selected schedule.

![Switch Work Shift from My Attendance](/images/attendance/switch-workshift.png)

<Callout type="info">
  Switching the Work Shift changes the schedule used to view your attendance. It
  does not change your Work Shift assignment or modify the original attendance records.
</Callout>

## Navigate and Filter Records

### Navigate by month

Use the arrows on either side of the month to move to the previous or next month. To move to a different period more quickly, select the displayed month and year, then choose the target month and year from the selector.

### Filter by attendance status

The filter bar shows **All** and the attendance statuses that occur in the selected month. **All** is selected by default. Select a status directly to show only the dates with that status.

![Navigate by month and filter attendance records by status](/images/attendance/my-attendance-filter.png)

The separators in the filter bar identify three status groups:

| Group | Status or application type | Description |
| --- | --- | --- |
| Basic attendance status | **On Time** | The recorded working time follows the schedule of the selected Work Shift. |
| Basic attendance status | **Early** | The employee checked out before the scheduled end time. |
| Basic attendance status | **Late** | The employee checked in after the scheduled start time. |
| Basic attendance status | **Missing** | A check-out record is missing. |
| Basic attendance status | **No Check In** | Both check-in and check-out records are missing. |
| Application-based status | **Leave** | Attendance affected by an approved leave application. |
| Application-based status | **Regularized (Correct Time)** | Attendance updated through an approved time-correction application. |
| Application-based status | **Overtime** | Attendance associated with an approved overtime application. |
| Custom status | Company-defined | A status defined by the company for its own business rules. |

<Callout type="info">
  **Leave**, **Regularized (Correct Time)**, and **Overtime** describe application
  types. Company Admins can change their displayed status names, so the labels in
  your filter may differ. Custom statuses are also named and configured by the company.
</Callout>

### Monthly table columns

Each row represents one date and displays:

| Information | Description |
| --- | --- |
| Date | The attendance date and day of the week. |
| Check In | Your recorded check-in time. |
| Check Out | Your recorded check-out time. |
| Current Status | The status selected from the records that apply to the date. |
| Change Time To | The corrected check-in and/or check-out time you want to request. |
| Reason | The required reason for an attendance correction. |

Original source records are read-only. Applications add new records instead of overwriting them. See [Attendance Record Details](/en/docs/user/my-attendance/record-details) to learn how the history is preserved.

## Business Rules

<Accordions>

<Accordion title="Can I see another employee's attendance?">

No. My Attendance only displays records belonging to the account currently signed in.

</Accordion>

<Accordion title="Can Company Admins use My Attendance?">

Yes. A Company Admin can open My Attendance from the admin sidebar, but the page still displays only that admin's own attendance records.

</Accordion>

<Accordion title="Does switching the Work Shift change my assignment?">

No. It changes the schedule used to display and evaluate the records; it does not update your Work Shift assignment or original attendance data.

</Accordion>

</Accordions>

## Troubleshooting

### My Attendance is missing from the sidebar

**Why this happens:** Attendance is not enabled for your company.

**How to fix it:** Ask a Company Admin or Super Admin to check the company feature configuration.

### “No attendance data available yet.”

**Why this happens:** No records exist for the selected Work Shift and month.

**How to fix it:** Confirm the Work Shift and month. If they are correct, ask a Company Admin whether attendance data has been imported.

### Switching Work Shift does not change my assignment

**Why this happens:** The selector changes only the schedule used to display and evaluate the page.

**How to fix it:** Ask a Company Admin if your Work Shift setup needs to change.

**自分の勤怠** はログイン中のアカウントの記録だけを表示します。一般ユーザーと会社管理者が利用できます。

## 始める前に

- **必要な権限:** 一般ユーザーまたは会社管理者。
- **必要な機能:** 会社で勤怠が有効で、勤務シフトが1件以上あること。
- **作業時間の目安:** 約2分。

## 自分の勤怠を開く

サイドメニューで **自分の勤怠** を選択します。

**結果:** デフォルトのシフトが開きます。デフォルトがない場合は最初のシフトが開きます。

![一般ユーザーのメニュー](/images/attendance/access-menu-user-side.png)

![会社管理者のメニュー](/images/attendance/access-menu-admin-side.png)

## 勤務シフトと月を選択する

上部の一覧から勤務シフトを選択します。左右の矢印または月・年の選択で月を変更します。

**結果:** 選択した予定と月の記録が表示されます。切り替えは本人のシフト割り当てや元のデータを変更しません。

![シフトの切り替え](/images/attendance/switch-workshift.png)

## ステータスで絞り込む

**すべて** または当月にあるステータスを選択します。基本ステータス、Leave・Regularized・Overtimeなどのテンプレート連動ステータス、会社独自のステータスが区分されています。

![月とステータスの選択](/images/attendance/my-attendance-filter.png)

申請に連動するステータス名は会社が設定するため、画像と異なる場合があります。

## 一覧の項目

| 項目 | 内容 |
| --- | --- |
| 日付 | 日付と曜日 |
| 出勤 / 退勤 | 記録された時刻 |
| 現在のステータス | 優先順位で選択されたラベル |
| 変更後の時刻 | 修正や申請に使用する時刻 |
| 理由 | 申請の説明 |
| 操作 | 三点メニューから申請を選択 |

元の記録は読み取り専用です。日付を選択して履歴を確認できます。勤務日では時刻と理由を入力して申請を開始できます。休日には入力欄がありませんが、メニューから申請を開き、フォームで入力できます。

## トラブルシューティング

### 自分の勤怠メニューがない

会社管理者に勤怠機能の設定を確認してもらってください。

### 記録がない

シフトと月を確認し、正しければデータがインポートされているか管理者に確認してください。

### 他の社員を表示できない

この画面は本人の記録だけを表示します。会社管理者は **勤怠管理** を使用します。

### 切り替えてもシフトの割り当てが変わらない

表示・評価用の予定を切り替える操作です。本人の設定変更が必要な場合は会社管理者に連絡してください。

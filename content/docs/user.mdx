---
title: User (Employee)
description: Everyday features for employees — applications, approvals, and attendance
icon: User
---

- **My Applications** — list of submitted applications, status tracking, detail/report views
- **Create Application** — create and submit a new application per the configured approval route
- **Approve** — approval inbox, with bulk approve/reject actions
- **Management** — an aggregated view of applications for users with oversight permissions
- **My Attendance** — personal attendance history, detail by work shift
- **Representative** — set up/view delegate-approver history (employee side)

<Callout type="info">
  **Management vs. My Applications**: the precise boundary between these two screens (permissions,
  data scope shown) still needs confirmation from the development team.
</Callout>

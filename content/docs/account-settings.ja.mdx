# アカウント設定

<Callout type="info">
**アカウント設定**ページでは、各ユーザーが自分自身のアカウント情報(個人情報、プロフィール画像、表示言語、タイムゾーン、パスワードなど)を管理できます。

このページでの変更は、現在ログイン中のアカウントにのみ反映されます。

</Callout>

## 概要

アカウント設定は、以下の2つのセクションで構成されています。

- **Profile Information(プロフィール情報)** — 個人情報とプロフィール画像を更新します。
- **Password(パスワード)** — アカウントのパスワードを変更します。

ユーザーは、画面右上のアバターをクリックし、**Profile** を選択することでこのページにアクセスできます。

![User Menu](/images/account-user-menu.png)

---

## Profile Information(プロフィール情報)

**Profile Information** タブには、ユーザーの個人情報と現在のプロフィール画像が表示されます。

ユーザーができること:

- プロフィール画像を更新する。
- 個人情報を編集する。
- 表示言語を設定する。
- タイムゾーンを選択する。

![Profile Information](/images/profile-information.png)

---

### プロフィール画像の更新

Workflow では、ユーザーがプロフィール画像を自由にカスタマイズできます。

対応している画像形式:

- JPG
- JPEG
- PNG

最大ファイルサイズ:

- **800 KB**

ユーザーができること:

- 新しいプロフィール画像をアップロードする。
- 現在のプロフィール画像を差し替える。
- 現在のプロフィール画像を削除し、デフォルトのアバターに戻す。

<Callout type="tip">
  プロフィール画像を更新すると、Workflow
  全体に表示されるアバターが即座に変更されます。
</Callout>

---

### 個人情報の更新

個人情報を更新するには **Edit** をクリックします。

![Update Personal Information](/images/profile-edit-dialog.png)

ユーザーが変更できる項目:

| 項目         | 説明                                                |
| ------------ | --------------------------------------------------- |
| Email        | 登録済みのメールアドレス。                          |
| Full Name    | ユーザーの表示名。                                  |
| Phone Number | 連絡先電話番号。                                    |
| Timezone     | Workflow 全体で使用されるデフォルトのタイムゾーン。 |
| Language     | 表示言語。                                          |
| Address      | ユーザーの住所。                                    |

保存後、更新した情報はシステム全体に即座に反映されます。

---

### 言語(Language)

Workflow は現在、以下の言語に対応しています。

- English(英語)
- Vietnamese(ベトナム語)
- Japanese(日本語)

言語を変更すると、他のユーザーに影響を与えることなく、即座にアプリケーションの表示言語が切り替わります。

---

### タイムゾーン(Timezone)

設定したタイムゾーンは、以下の日時情報の表示に使用されます。

- 申請の日付
- 承認履歴
- アクティビティのタイムスタンプ
- 通知
- その他の日時情報

---

## パスワードの変更

ユーザーは **Password** タブからパスワードを変更できます。

![Change Password](/images/change-password.png)

パスワードを変更するには、以下の情報を入力する必要があります。

- 現在のパスワード
- 新しいパスワード
- 新しいパスワード(確認)

### パスワードの要件

新しいパスワードは、以下の条件をすべて満たす必要があります。

- **8文字以上**
- **数字を1文字以上**含む
- **大文字を1文字以上**含む
- **小文字を1文字以上**含む
- **特殊文字を1文字以上**含む

Workflow はパスワードを更新する前に、各条件を検証します。

## 業務ルール

<Accordions>

<Accordion title="他のユーザーのプロフィールを編集できますか?">

いいえ。

ユーザーは自分自身のアカウント情報のみ編集できます。

</Accordion>

<Accordion title="言語を変更すると、他のユーザーに影響しますか?">

いいえ。

言語設定はユーザーごとに個別に保存されます。

</Accordion>

<Accordion title="新しいプロフィール画像はいつから反映されますか?">

アップロードが成功すると、新しいプロフィール画像は即座に適用されます。

</Accordion>

<Accordion title="パスワードを変更する際、現在のパスワードの入力は必須ですか?">

はい。

新しいパスワードを設定する前に、現在のパスワードを入力して本人確認を行う必要があります。

</Accordion>

</Accordions>

---
title: Application Detail
description: View a submitted application's form data, approval progress, and comments
icon: FileSearch
---

The Application Detail page shows everything about one submitted application:

- **Form Information** — the filled-in form data.
- **Route Section** — approval progress, showing each step and its approver; supports ad-hoc
  changes to the route (adding or removing an approver) when permitted.
- **Comment Section** — a comment thread on the application (hidden while the application is still
  a Draft).
- Links to any linked parent or children applications.

<Callout type="info">
  What an individual user can view or edit on this page depends on their role in the current
  approval step (applicant vs. approver) and the application's status.
</Callout>

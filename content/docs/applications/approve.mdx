---
title: Approve
description: Approval inbox for applications waiting on the current user
icon: SquareCheck
---

**Approve** is the approval inbox — applications currently waiting for the current user's
decision.

- Defaults to a **Waiting For Me** filter chip (removable).
- A full filter panel is available (department, category, date range, and more).
- Supports bulk approve/reject actions across multiple selected applications.

<Callout type="tip">
  The sidebar badge next to Approve shows the current count of applications waiting on the user.
</Callout>

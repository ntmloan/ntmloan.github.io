**My Applications** lists every application the current user has submitted, with search and a
filter panel (status, category, application definition, submitted-date range, applied-date range).

## Application Status

Drafted, Canceled, In Progress, Denied, Sent Back, Approved, Waiting For Me, Confirm Denied,
Report, Expired.

Users can select one or more applications for bulk actions (for example, Cancel), or open an
application to view its full detail and approval progress.

<Callout type="tip">
  Use **Create New Application** to start a new application — pick a department, then a category,
  then the specific Application Definition to apply for.
</Callout>

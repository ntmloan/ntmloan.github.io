---
title: Report Application
description: File a follow-up report derived from an already-approved parent application
icon: FileClock
---

**Report Application** lets a user file a report-type application derived from a parent application
that has already been approved — used for applications configured with a "Report" definition
linked from their Application Definition.

The report flow reuses the same submission behavior as **Create Application** (including duplicate
detection), but is always tied back to its parent application.

<Callout type="tip">
  A Report definition is created from within its parent Application Definition (see **Create
  Report Application** in Application Definitions).
</Callout>

# 従業員管理

<Callout type="info">
従業員管理は、会社内のすべてのユーザーを管理するための中心的な機能です。

管理者は、従業員アカウントを個別または一括で作成し、アカウントのステータスを管理し、ユーザー情報を更新し、管理業務のために従業員データをエクスポートできます。

</Callout>

## 概要

**従業員一覧(Employee List)** には、Workflow にアクセスできるすべての従業員が表示されます。

このページから、管理者は以下を行うことができます。

- 従業員情報を確認する。
- 従業員を検索・フィルターする。
- 新しい従業員アカウントを作成する。
- Excel テンプレートを使って従業員をインポートする。
- 従業員情報をエクスポートする。
- 従業員情報を更新する。
- 従業員アカウントを削除する。

![Employee List](/images/employee-list.png)

---

## 従業員一覧(Employee List)

従業員一覧には、現在の会社に所属するすべての従業員が表示されます。

各行は、1つの従業員アカウントとその現在のステータス、プロフィール情報を表します。

### 従業員情報

一覧には以下の情報が表示されます。

| 列                 | 説明                                                       |
| ------------------ | ------------------------------------------------------------ |
| Status(ステータス) | 従業員アカウントが Active(有効)か Inactive(無効)かを表示。 |
| Code(コード)       | 従業員の内部コード。                                          |
| Full Name(氏名)    | 従業員の表示名。                                              |
| Email              | 登録済みのメールアドレス。                                    |
| Joined Date(入社日) | 従業員の入社日。                                              |
| Start Using Date(利用開始日) | アカウントがログイン可能になる日。                    |
| End Using Date(利用終了日)   | アカウントの有効期限。                                |
| Language(言語)     | ユーザーインターフェースの言語。                              |
| Action(操作)       | 従業員の編集または削除。                                      |

---

### 従業員のステータス

Workflow では、2つのアカウントステータスがあります。

| ステータス | 説明                                                             |
| ---------- | ------------------------------------------------------------------ |
| Active     | 設定された利用期間内であれば、従業員は Workflow にアクセスできます。 |
| Inactive   | アカウントが無効化されており、Workflow にアクセスできません。      |

<Callout type="tip">
  現在の日付が設定された利用期間の範囲外になった場合も、従業員のアカウントは自動的に利用不可になります。
</Callout>

---

## 従業員の検索

管理者は検索ボックスを使って従業員を素早く見つけることができます。

以下の項目で検索できます。

- 従業員コード
- 従業員名
- メールアドレス

検索キーワードを変更すると、従業員一覧が即座に更新されます。

---

## 従業員のフィルター

**Filter** をクリックすると、従業員一覧を絞り込むことができます。

![Employee Filter](/images/employee-filter.png)

利用可能なフィルター:

| フィルター         | 説明                             |
| ------------------ | -------------------------------- |
| Department(部署)   | 部署で従業員を絞り込みます。     |
| Status(ステータス) | Active または Inactive。         |
| Joined Date(入社日) | 入社日の範囲で従業員を絞り込みます。 |

複数のフィルターを組み合わせることができます。

管理者ができること:

- フィルターを適用する
- すべてのフィルターをリセットする
- 変更を適用せずにフィルターパネルを閉じる

---

## 従業員の追加

Workflow では、従業員アカウントを作成する方法が2つ用意されています。

- 従業員を1人ずつ追加する
- 複数の従業員をインポートする

![Add Employee Menu](/images/add-employee-menu.png)

---

### 従業員を1人追加する

**Add New Employee → Add one employee** をクリックします。

![Add Employee](/images/add-employee-dialog.png)

管理者は以下の情報を設定できます。

| 項目                          | 必須     | 説明                                       |
| ----------------------------- | :------: | ------------------------------------------ |
| Email                         |   ✅     | 従業員のログインアカウント。               |
| Full Name(氏名)               |   ✅     | 従業員の表示名。                           |
| Active                        |   ✅     | アカウントを有効にするかどうかを決定。     |
| User Type(ユーザー種別)       |   ✅     | ユーザーの権限レベル。                     |
| Code(コード)                  |  任意    | 従業員の内部コード。                       |
| External ID                   |  任意    | 外部連携で使用される識別子。               |
| Phone Number(電話番号)        |  任意    | 従業員の連絡先電話番号。                   |
| Joined Date(入社日)           |  任意    | 従業員の入社日。                           |
| Start Using Date(利用開始日)  |   ✅     | 従業員が Workflow にアクセスできる最初の日。 |
| End Using Date(利用終了日)    |  任意    | アカウントの有効期限。                     |
| Timezone(タイムゾーン)        |  任意    | 従業員のタイムゾーン。                     |
| Language(言語)                |  任意    | 表示言語。                                 |

---

### ユーザー種別(User Type)

Workflow は現在、2種類のユーザー種別に対応しています。

| ユーザー種別 | 説明                                                     |
| ------------ | -------------------------------------------------------- |
| User         | 標準の従業員アカウント。                                 |
| Admin        | 管理機能にアクセスできる、会社の管理者アカウント。         |

<Callout type="info">
  従業員管理、組織管理、申請定義、会社設定などの管理機能にアクセスできるのは、会社の管理者(Company Administrator)のみです。
</Callout>

---

### 従業員のアカウント利用可否

アカウントを利用できるかどうかは、**Status(ステータス)** と **Usage Period(利用期間)** の両方によって決まります。

従業員が Workflow にアクセスできるのは、以下をすべて満たす場合のみです。

- Status が **Active** であること。
- 現在の日付が **Start Using Date** 以降であること。
- 現在の日付が **End Using Date**(設定されている場合)より前であること。

---

### External ID

**External ID** フィールドは、外部の人事(HR)システム、ERP、または ID 管理システムとの連携を目的としています。

Workflow はこの値に対して、フォーマットの制限を設けていません。

---

### 従業員コード(Employee Code)

従業員コードは、従業員の内部識別子です。

主に以下の目的で使用されます。

- 人事管理
- 外部システムとの同期
- 社内レポート

---

## 従業員の編集

管理者は、いつでも従業員情報を更新できます。

従業員の操作メニューから **Edit** を選択します。

変更内容は、保存後すぐに反映されます。

編集できる情報:

- 個人情報
- ステータス
- 利用期間
- 言語
- タイムゾーン
- 連絡先情報

---

## 従業員の削除

従業員の操作メニューから **Delete** を選択します。

削除の前に、Workflow は確認ダイアログを表示します。

![Delete Employee](/images/delete-employee.png)

<Callout type="warning">
従業員を削除すると、そのアカウントは会社から完全に削除されます。

その従業員が他の Workflow の設定で参照されている場合、それらの参照が解除されるまで削除が制限されることがあります。

</Callout>

---

## 業務ルール

<Accordions>

<Accordion title="従業員を管理できるのは誰ですか?">

会社の管理者(Company Administrator)のみが、従業員アカウントの作成、更新、インポート、エクスポート、削除を行えます。

</Accordion>

<Accordion title="2人の従業員が同じメールアドレスを使用できますか?">

いいえ。

メールアドレスはログインアカウントとして使用されるため、各従業員は一意のメールアドレスを持つ必要があります。

</Accordion>

<Accordion title="従業員コードは必須ですか?">

いいえ。

従業員コードは任意項目であり、社内管理や外部連携に使用できます。

</Accordion>

<Accordion title="External ID は必須ですか?">

いいえ。

External ID は任意項目で、主に外部システムとの連携を目的としています。

</Accordion>

<Accordion title="Inactive の従業員はログインできますか?">

いいえ。

Inactive の従業員は、設定された利用期間に関わらず Workflow にアクセスできません。

</Accordion>

</Accordions>

---

## 従業員のインポート

Workflow では、Excel テンプレートを使って従業員を一括作成できます。

管理者は一度の操作で複数の従業員をインポートでき、入社対応時の手作業でのデータ入力を大幅に削減できます。

**Add New Employee → Import employee** をクリックします。

![Import Employee](/images/import-employee-dialog.png)

---

### インポートテンプレートのダウンロード

従業員をインポートする前に、Workflow が提供する最新のテンプレートをダウンロードしてください。

テンプレートには以下が含まれます。

- 必須項目の列。
- 任意項目の列。
- サンプルデータ。
- 対応しているデータ形式。

公式テンプレートを使用することで、インポート時のバリデーションエラーを防ぐことができます。

---

### インポートファイルの準備

テンプレートに従って従業員情報を入力します。

主な項目:

| 項目                          | 必須   |
| ----------------------------- | :----: |
| Email                         |  ✅    |
| Full Name(氏名)               |  ✅    |
| User Type(ユーザー種別)       |  ✅    |
| Status(ステータス)            |  ✅    |
| Start Using Date(利用開始日)  |  ✅    |
| Employee Code(従業員コード)   | 任意   |
| External ID                   | 任意   |
| Phone Number(電話番号)        | 任意   |
| Joined Date(入社日)           | 任意   |
| End Using Date(利用終了日)    | 任意   |
| Timezone(タイムゾーン)        | 任意   |
| Language(言語)                | 任意   |

<Callout type="tip">
  テンプレートの列名やシート構成を変更しないでください。
</Callout>

---

### ファイルのアップロード

テンプレートの準備が完了したら:

<Steps>

#### インポートファイルを選択する

パソコン上で作成した Excel ファイルを選択します。

#### データを検証する

Workflow は、インポートを実行する前にすべての従業員データを検証します。

検証内容:

- 必須項目
- メールアドレスの重複
- 無効な日付形式
- 無効な言語の値
- 無効なユーザー種別の値

#### 従業員をインポートする

検証に成功すると、有効な従業員データがすべて自動的に作成されます。

</Steps>

---

### インポートの検証

検証に失敗した場合、インポートはキャンセルされ、Workflow は該当するバリデーションエラーを表示します。

よくあるバリデーションエラー:

- 必須項目の未入力。
- メールアドレスの重複。
- 無効な日付の値。
- 無効なユーザー種別。
- 無効な言語。
- ファイル形式が正しくない。

管理者はデータを修正し、ファイルを再度アップロードしてください。

---

## 従業員のエクスポート

従業員情報は、いつでもエクスポートできます。

従業員一覧ページで **Export** をクリックします。

Workflow は従業員情報を含む Excel ファイルを生成します。

![Export Employees](/images/export-employees.png)

---

### エクスポートの動作

エクスポートされるファイルには、従業員一覧に現在表示されているすべての従業員が含まれます。

検索条件やフィルターが適用されている場合は、絞り込まれた結果のみがエクスポートされます。

エクスポートされる情報:

- 従業員のプロフィール
- ステータス
- ユーザー種別
- 連絡先情報
- 利用期間
- 言語
- タイムゾーン

---

## 従業員のライフサイクル

従業員アカウントは、一般的に以下のライフサイクルをたどります。

```text
従業員を作成
        │
        ▼
Active(有効)
        │
        ├─────────────► 情報を更新
        │
        ├─────────────► 利用期間を変更
        │
        ├─────────────► 無効化
        │
        ▼
Inactive(無効)
        │
        ▼
削除(任意)
```

## ベストプラクティス

<Callout type="tip">

従業員を管理する際は、以下の推奨事項を参考にしてください。

- 人事システム全体で従業員コードを一貫して使用する。
- 新しい従業員の初出社日より前に Start Using Date を設定しておく。
- 過去の Workflow の記録を保持する必要がある場合は、従業員を削除するのではなく End Using Date を設定する。
- External ID は、外部システムと連携する場合にのみ使用する。
- 大人数の入社対応には Import Employee を使用する。

</Callout>

## 業務ルール

<Accordions>

<Accordion title="既に存在する従業員をインポートできますか?">

設定された一意の識別子(通常は Email)に基づいて、インポートしようとした従業員が既に存在する場合、Workflow は新しいアカウントを作成せず、その重複レコードを拒否します。

</Accordion>

<Accordion title="Start Using Date が未来の日付の場合、どうなりますか?">

従業員アカウントは正常に作成されますが、設定した Start Using Date になるまでサインインできません。

</Accordion>

<Accordion title="End Using Date を過ぎるとどうなりますか?">

現在の日付が End Using Date を超えると、その従業員アカウントはログインできなくなります。

</Accordion>

<Accordion title="エクスポートは検索フィルターを考慮しますか?">

はい。

エクスポートは、常に従業員一覧に表示されている現在の検索キーワードとフィルター条件に従います。

</Accordion>

<Accordion title="インポートされた従業員はすぐに通知を受け取れますか?">

はい。

従業員アカウントが有効になり、利用期間内であれば、手動で作成した従業員と同様に、すぐに Workflow を利用できます。

</Accordion>

</Accordions>

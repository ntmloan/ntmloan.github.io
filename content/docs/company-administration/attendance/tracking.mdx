Use Attendance Tracking to review employees in one Work Shift across a selected month. Each row is an employee, and each timeline item represents the status recorded for a day.

## Before you start

- **Required role:** Company Admin
- **Required feature:** Attendance must be enabled
- **You'll need:** At least one Work Shift
- **For populated results:** Import attendance data for the selected Work Shift

## Open the monthly view

1. In the admin sidebar, go to **Attendance Tracking**.
2. Select the arrow on the Work Shift you want to review.

**Expected result:** The Attendance Tracking timeline opens for the current month.

![Monthly Attendance Tracking timeline](/images/attendance/monthly-record.png)

If no records have been imported, the page displays **No attendance data available yet.** Use **Import Attendance Data** to add records.

## Change the month

Use the left or right arrow beside the displayed month, or select the month name and choose another month.

**Expected result:** The timeline reloads the selected month and returns to the first page of employees.

## Search for an employee

Enter the employee name or External ID in the search field.

**Expected result:** The timeline displays matching employees in the selected Work Shift and month.

## Filter the timeline

1. Select **Filter**.
2. Select one or more **Departments**.
3. Select one or more **Statuses**.
4. Select **Apply**.

**Expected result:** The timeline reloads with records that match the selected filters.

![Attendance filters](/images/attendance-filter.png)

Select **Reset** to remove both filters. Filters on the main timeline do not change the filters inside **Attendance Summary**.

## Read the timeline

The legend below the timeline identifies built-in and application-based statuses. A day can contain more than one record, such as regular working time and approved overtime.

| Status | Meaning |
| --- | --- |
| **Not Started** | The scheduled date is before the employee's attendance start date. |
| **No Check In** | A scheduled day has no check-in. |
| **Missing** | A check-in exists but the check-out is missing. |
| **Late** | Check-in is after the Work Shift start time. |
| **Early** | Check-out is before the Work Shift end time. |
| **On Time** | The record is neither late, early, nor missing. |
| **Weekly off** | The date is outside the Work Shift's working days. |

See [Understand attendance statuses](/en/docs/company-administration/attendance/status) for application-based statuses and display priority.

## Inspect one day

1. Select an attendance item on the timeline.

**Expected result:** **Detail Attendance Information** opens for the employee and date.

![Attendance details](/images/attendance-detail.png)

2. Review each record's **Time**, **Status**, **Record by**, **Approval status**, and **Additional (approval)** information.
3. If a status is linked to an application, select its link icon to open that application in a new tab.

**Expected result:** You can distinguish imported source records from records created by attendance applications without changing either one.

## Send an attendance reminder

1. Open **Detail Attendance Information** for the employee and date.
2. Select **Send Reminder**.
3. Optionally select a **Status**.
4. Select **Send Reminder**.

**Expected result:** Workflow sends the employee an attendance reminder. When the selected status is linked to an application form, the email includes a direct link to that form; otherwise it sends a general reminder for the date.

![Send Attendance Reminder](/images/send-attendance-reminder.png)

## Review monthly totals

1. Select **Summary** above the timeline.

**Expected result:** **Attendance Summary** opens with one column for each available status and one row per employee.

![Attendance Summary with month selector, search, department filter, and status totals](/images/attendance-tracking.png)

2. Change the month, search for an employee, or select **Filter** to filter by department.

**Expected result:** The summary reloads independently from the main timeline.

## Troubleshooting

### “No attendance data available yet.”

**Why this happens:** No attendance records exist for the selected Work Shift and period.

**How to fix it:** Confirm the Work Shift and month, then [import attendance data](/en/docs/company-administration/attendance/import).

### An employee is missing from the timeline

**Why this happens:** Search or filters are active, the employee does not belong to the selected result set, or the wrong Work Shift is open.

**How to fix it:** Clear the search, select **Filter** > **Reset**, and confirm the Work Shift.

### The displayed status is not the latest record chronologically

**Why this happens:** The monthly display uses status priority when several records apply to one date.

**How to fix it:** Open **Detail Attendance Information** to review all records, then see [status priority](/en/docs/company-administration/attendance/status#status-priority).

### The timeline is difficult to use on a small screen

**Why this happens:** Attendance Tracking is a wide, day-based timeline.

**How to fix it:** Use a desktop browser and scroll horizontally through the month.

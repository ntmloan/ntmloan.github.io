Use this page when an Attendance menu, action, or result is not available as expected.

## Before you start

- **Required feature:** Attendance must be enabled for the company
- **Administrator tasks:** Require the Company Admin role
- **Employee tasks:** Available from **My Attendance** to Standard Users and Company Admins

## Access requirements

Attendance pages require the company's Attendance feature to be enabled. The interface also separates administrator and employee tasks:

| Task | Company Admin | Standard User |
| --- | :---: | :---: |
| Open **My Attendance** and view own records | Yes | Yes |
| Create applications from own attendance | Yes | Yes |
| Open **Attendance Tracking** | Yes | No |
| Create, edit, activate, or delete Work Shifts | Yes | No |
| Import and review employee attendance | Yes | No |
| Configure attendance statuses | Yes | No |
| Send reminders | Yes | No |

## Recommended setup order

1. Enable Attendance for the company.
2. Create and activate a Work Shift.
3. Mark the preferred Work Shift as default.
4. Install the Attendance Application Templates required by the company.
5. Configure any company-specific application-based statuses.
6. Import attendance data.
7. Ask employees to review **My Attendance**.

## Frequently asked questions

### Can one employee have several records on the same date?

Yes. Imported attendance, corrections, leave, overtime, and other approved applications can create separate records. **Detail Attendance Information** preserves them, while status priority selects the result displayed in the monthly view.

### Does an application overwrite imported attendance?

No. It creates an additional record. The source record remains in the history.

### Can a Work Shift cross midnight?

No. The current Work Shift form and backend require **End Time** to be after **Start Time** on the same day.

### Can an existing Work Shift schedule be changed?

Yes, until attendance records use it. Once it is in use, its working days and time fields are locked. Name, description, active status, and default status can still be changed.

### Can an in-use Work Shift be deleted?

No. Turn off **Active** instead so historical data remains available.

### Why does My Attendance open a different Work Shift?

It opens the default Work Shift. If none is default, it opens the first available Work Shift. Selecting another Work Shift changes only the displayed schedule; it does not reassign the employee.

### Does changing a status name change its priority?

No. Template-created Regularization and Leave records are identified by template code, not by their visible label.

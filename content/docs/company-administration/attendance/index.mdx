A Work Shift defines the working days, start and end times, and optional break period used to evaluate attendance. Complete this setup before importing attendance data or asking employees to use **My Attendance**.

## Before you start

- **Required role:** Company Admin
- **Required feature:** Attendance must be enabled for the company
- **You'll need:** The working days and hours for the schedule
- **Estimated completion time:** About 5 minutes per Work Shift

<Callout type="info">
  The Attendance menu is hidden when the Attendance feature is not enabled for the company.
</Callout>

## Create a Work Shift

1. In the admin sidebar, go to **Attendance Tracking**.
2. Select **Create Work Shift**.

**Expected result:** The **Create New Work Shift** dialog opens.

![Create Work Shift](/images/create-work-shift.png)

3. Enter a **Work Shift Name**, for example `Office hours`.
4. Select at least one **Working Day**. You can use **All Days**, **Weekday (Mon - Fri)**, **Weekend (Sat - Sun)**, or individual days.
5. Select a **Start Time** and an **End Time**, for example `08:30` and `17:30`.
6. If the schedule has a break, select **Break Start Time** and **Break End Time**, for example `12:00` and `13:00`.
7. Optionally enter a **Description**, for example `Default schedule for office employees`.
8. Turn on **Active** when the Work Shift is ready to use.
9. Optionally select **Set as default work shift for attendance tracking**.
10. Select **Create**.

**Expected result:** The dialog closes and the new Work Shift appears on the **Select Work Shift** page.

<Callout type="warning">
  **End Time** must be after **Start Time** on the same day. Overnight Work Shifts are not supported. A break must fall inside the Work Shift and its end time must be after its start time.
</Callout>

## Understand Active and Default

- **Active** makes the Work Shift available for attendance use. A newly created Work Shift is inactive unless you turn this option on.
- **Set as Default** makes the Work Shift the first schedule opened in **My Attendance**. Only one Work Shift can be default; selecting a new default replaces the previous one.
- If no Work Shift is marked as default, **My Attendance** opens the first available Work Shift.

## Open a Work Shift

1. Go to **Attendance Tracking**.
2. Find the required Work Shift.
3. Select the arrow on its card.

**Expected result:** The monthly Attendance Tracking page opens for that Work Shift.

![Work Shift list](/images/work-shift-list.png)

## Edit a Work Shift

1. Go to **Attendance Tracking**.
2. Select the pencil icon on the Work Shift card.
3. Update the available fields.
4. Select **Save**.

**Expected result:** The card displays the saved name, schedule, status, and default setting.

You can change the working days and times while the Work Shift has no attendance records. After it has been used by a timesheet, you can still change its name, description, **Active** setting, and default setting, but you cannot change its schedule.

## Delete an unused Work Shift

<Callout type="warning">
  Deleting a Work Shift cannot be undone. A Work Shift that already has attendance records cannot be deleted.
</Callout>

1. Go to **Attendance Tracking**.
2. Select the trash icon on the Work Shift card.
3. Review the confirmation dialog.
4. Select **Delete**.

**Expected result:** The Work Shift is removed from the list. If it is already in use, Workflow keeps it and displays an error instead.

## Limits

The current interface allows up to five Work Shifts. When five cards exist, **Create Work Shift** is no longer displayed.

## Troubleshooting

### The Attendance Tracking menu is missing

**Why this happens:** Attendance is not enabled for the company, or your account is not a Company Admin or Super Admin.

**How to fix it:** Ask the person who manages company features and roles to verify the Attendance feature and your Company Admin role.

### A time field shows a validation error

**Why this happens:** **End Time** is not after **Start Time**, or the break is outside the Work Shift.

**How to fix it:** Keep all times within one calendar day and place the complete break between the Work Shift start and end.

### The schedule cannot be changed

**Why this happens:** Attendance records already use this Work Shift.

**How to fix it:** Keep the existing Work Shift for historical data and create another Work Shift with the new schedule.

### The Work Shift cannot be deleted

**Why this happens:** The Work Shift already has attendance records.

**How to fix it:** Turn off **Active** to prevent new use while preserving existing attendance history.

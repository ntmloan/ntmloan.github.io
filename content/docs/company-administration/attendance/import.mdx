Import an Excel file exported by your attendance device or source system. Workflow processes the file in the background, so you can continue working while the import runs.

## Before you start

- **Required role:** Company Admin
- **Required feature:** Attendance must be enabled
- **You'll need:** An active Work Shift and one Excel file in the supported attendance format
- **Employee matching:** Each Personal ID in the file must match an employee's External ID in Workflow
- **Estimated completion time:** Upload takes less than a minute; processing time depends on file size

<Callout type="warning">
  Do not change the column order in the source file. Workflow reads fixed columns, including Time, event information, Personal ID, employee name, department, reader, and verification mode.
</Callout>

## Import the file

1. In the admin sidebar, go to **Attendance Tracking**.
2. Open the Work Shift that should receive the records.
3. Select **Import Attendance Data**.

**Expected result:** The **Import Attendance Data** dialog opens.

![Import Attendance Data](/images/import-attendance-data.png)

4. Drag one Excel file into the upload area, or select the area and choose the file.
5. Confirm that the selected file name appears in the dialog.
6. Select **Import**.

**Expected result:** The dialog closes and an import notification appears in the lower-right corner. You can continue using Workflow while processing runs.

## Review the result

When processing finishes, the notification shows the result. Select **View import details** to review:

- Processed rows
- Successful records
- Skipped duplicate records
- Excluded action-only records
- External IDs that could not be found
- Records with a missing External ID

![Import details with processed, successful, skipped, excluded, and unmatched records](/images/attendance/import-detail-dialog.png)

After a successful import, return to the selected month in Attendance Tracking and confirm that the employee records appear.

<Callout type="info">
  A missing or unknown Personal ID does not match an employee. Workflow reports those rows as warnings instead of attaching them to another employee.
</Callout>

## Source file requirements

The importer expects the attendance time in `yyyy-MM-dd HH:mm:ss` format. It reads the following source information:

| Source information | Use |
| --- | --- |
| Time | Date and time of the attendance event |
| Area, device and event fields | Context from the attendance device |
| Personal ID | Matches the record to an employee's External ID |
| First name and last name | Displayed in warning details |
| Department, reader and verification mode | Additional source context |

## Troubleshooting

### “Please select a file.”

**Why this happens:** No file is attached to the dialog.

**How to fix it:** Add one Excel file and wait for its name to appear before selecting **Import**.

### Import failed

**Why this happens:** The file is not a supported Excel file, its structure is different from the expected source format, or a time value cannot be read.

**How to fix it:** Export a new file from the supported attendance source, keep the original column order, and verify the `yyyy-MM-dd HH:mm:ss` time format.

### External IDs not found

**Why this happens:** A Personal ID in the file does not match any employee External ID in Workflow.

**How to fix it:** Correct the employee's External ID or the Personal ID in the source system, then import the corrected file.

### Some records were skipped or excluded

**Why this happens:** Duplicate events are skipped, and device events that do not represent attendance records are excluded.

**How to fix it:** Open **View import details**. Re-import only when the source data itself must be corrected.

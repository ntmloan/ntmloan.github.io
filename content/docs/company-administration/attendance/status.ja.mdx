ステータスは勤怠の結果を示します。基本ステータスは打刻と勤務シフトから判定され、申請に連動するステータスは承認済みの休暇、残業、勤怠修正、出張などから作成されます。

![勤怠ステータス](/images/attendance-status-list.png)

## 始める前に

- **必要な権限:** 会社管理者。勤怠機能が有効であること。
- **準備するもの:** 有効な勤務シフトと、承認ルートを持つ有効な申請定義。
- **フォームの条件:** 開始・終了に使用する異なる日付または日時フィールド2件。
- **作業時間の目安:** 約10分。

## 基本ステータス

| 表示 | 意味 |
| --- | --- |
| 出勤なし | 勤務日に出勤記録がない |
| 記録なし | その日のデータがない |
| 未開始 | 社員の勤怠開始日より前 |
| 時間通り | 勤務時間の条件を満たす |
| 遅刻 | 開始時間より後に出勤 |
| 早退 | 終了時間より前に退勤 |
| 欠勤（Missing） | 勤怠情報が不足している。代表例は退勤記録の欠落 |

**Leave**、**Overtime**、**Regularized** は申請に連動するステータスです。[勤怠申請テンプレート](/ja/docs/application-definitions/application-templates)をインストールすると、申請定義、ステータス、時間の対応付けが作成されます。システムテンプレートのステータスは名前と色のみ変更できます。

## 申請と記録の関係

名前、背景色、枠線色が表示を決めます。**申請** はフォームを指定し、**開始時間** と **終了時間** は異なる日時フィールドを対応付けます。承認後、送信された値から記録が追加され、元の打刻は保持されます。

![申請とステータスの対応](/images/attendance/how-attendance-status-work.jpg)

## カスタムステータスを作成する

出張、在宅勤務、研修、顧客訪問などに使用します。Leave、Overtime、Regularizedの名前や色だけを変える場合は、テンプレートで作成されたステータスを編集してください。

1. **Business Trip Request** などの申請定義を作成して有効にします。承認ルートと **Departure Time**、**Return Time** の2つの日時フィールドを用意します。

**結果:** 対応付けに使用できるフィールドが用意されます。

![出張の申請フォーム](/images/attendance/business-trip-application-definition.png)

2. **勤怠管理** で対象の勤務シフトを開きます。
3. 一覧下の **ステータスを追加** を選択します。

**結果:** 追加ダイアログが開きます。

![勤務シフトを選択](/images/attendance/choose-your-work-shift.png)

![ステータスを追加](/images/attendance/add-your-status.png)

4. **ステータス名** を入力します。例: `Business Trip`。最大20文字です。
5. **背景色** と **枠線色** を選択します。
6. カテゴリーと **申請** を選択します。
7. **開始時間** と **終了時間** に異なるフォームフィールドを対応付けます。
8. 必要に応じて **条件を追加** を選択し、選択肢フィールドの値を指定します。ドロップダウン、ラジオ、チェックボックスから最大2条件を設定できます。
9. 必要に応じて **勤務シフト外の時間を許可** をオンにします。
10. **作成** を選択します。

**結果:** シフトの凡例と **自分の勤怠** の申請メニューにステータスが表示されます。

![出張ステータスの設定](/images/attendance/business-trip-attendance-status.png)

![自分の勤怠から出張を申請](/images/attendance/business-trip-append-to-my-attendance.png)

カテゴリーと申請を選択すると対応付け可能なフィールドが読み込まれます。社員はステータスを選び、フォームに入力して承認ルートに送信します。

<Callout type="warning">
記録に適用済みのステータスでは、申請、時間の対応付け、条件、勤務時間外の設定は変更できません。名前と色は変更できます。使用済みのステータスは削除できません。
</Callout>

## 勤務時間外の記録

初期設定では申請の期間は勤務シフト内に限定されます。例えば終了が17:30のシフトで17:30–20:00の残業を記録する場合は、勤務シフト外の時間を許可してください。

## 表示の優先順位

同じ日に複数の記録がある場合、小さい数ほど優先されます。

| 優先順位 | ステータスまたはテンプレート |
| :---: | --- |
| 0 | 時間通り |
| 1 | Regularization — 勤怠修正 |
| 2 | 遅刻または早退 |
| 3 | Missing |
| 4 | Leave — 休暇 |
| 最後 | その他のステータス |

RegularizationとLeaveはテンプレートコードで判別されるため、名前を変えても優先順位は変わりません。優先順位は月次ラベルだけに影響し、元の記録を削除・上書きしません。

## トラブルシューティング

### 申請を選択できない

適切な申請定義がないか、別の有効なカスタムステータスに使用されています。申請定義を作成・有効化するか、未使用の申請を選択してください。

### 時間フィールドがない

異なる日付または日時フィールド2件をフォームに追加して、ダイアログを開き直してください。

### 設定がロックされている、または削除できない

読み込み完了を待ってください。テンプレート管理または使用済みの場合は名前・色のみ変更し、履歴のためステータスを保持してください。

Workflowは選択した勤務シフトに対して各日を評価します。予想と異なる結果を調べる際に利用してください。

## 始める前に

該当画面の閲覧権限、会社の有効な勤怠機能、勤務シフトの予定、**勤怠情報の詳細** の記録が必要です。

## 基本ステータスの判定順序

勤務日の場合、次の順序で確認します。

1. 社員の勤怠開始日より前: **未開始**。
2. 未来の日付で出勤記録がない: まだ結果を作成しません。
3. 当日または過去で出勤記録がない: **出勤なし**。
4. 当日または過去で出勤はあるが退勤がない: **欠勤（Missing）**。
5. 出勤がシフト開始より後: **遅刻**。
6. 遅刻でなく、退勤がシフト終了より前: **早退**。
7. その他: **時間通り**。

勤務日以外は **休日** と表示されます。遅刻と早退の両方に該当する記録は、判定順序により **遅刻** になります。

## 勤務日の照合

個別の曜日、全日、平日（月〜金）、週末（土・日）を指定できます。予定に一致する日だけが勤怠評価の対象です。

## 複数の記録がある場合

| 優先順位 | 記録 |
| :---: | --- |
| 0 | 時間通り |
| 1 | Regularizationテンプレート |
| 2 | 遅刻 / 早退 |
| 3 | Missing |
| 4 | Leaveテンプレート |
| 最後 | その他 |

小さい数ほど優先されます。RegularizationとLeaveは表示名ではなくテンプレートコードで判定されます。すべての記録は詳細に保持されます。

## 申請から作成される記録

連動ステータスは2つの日付または日時フィールドに対応付けられます。承認後、送信された値から記録が追加され、元の記録は保持されます。

**勤務シフト外の時間を許可** がオフの場合は期間がシフト内に制限されます。残業など、勤務前後の時間を含める場合はオンにします。

## 予想外の結果を調べる

1. 表示している勤務シフトを確認します。
2. 日付が勤務日に該当するか確認します。
3. **勤怠情報の詳細** を開きます。
4. 出退勤時刻と予定を比較します。
5. 申請に連動する記録と **承認ステータス** を確認します。

**結果:** 現在のラベルが判定ルールまたは優先順位で説明できるようになります。

## トラブルシューティング

### 休暇や修正が表示されない

申請が保留中または却下済みの可能性があります。リンクから申請と承認ルートを確認してください。

### 正しい時刻なのに遅刻と表示される

選択したシフトと正確な時刻を確認してください。そのシフトの開始時間と比較されています。

### 1日に複数のステータスがある

元の打刻と申請の記録が別々に保存されています。内容が正しければ修正は不要です。詳細で履歴を確認してください。

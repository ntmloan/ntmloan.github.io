title: Kết nối API
description: Kết nối nguồn dữ liệu bên ngoài để cung cấp dữ liệu cho trường dropdown và tra cứu
icon: Plug
---

Tab **Kết nối API (Get API)** thiết lập một API "tài nguyên" bên ngoài, dữ liệu từ đó có thể được
dùng để điền vào các trường dropdown hoặc tra cứu trong tab Biểu mẫu — ví dụ: lấy danh sách giá trị
từ hệ thống khác thay vì phải quản lý thủ công trong Workflow.

Sau khi một tài nguyên Get API được cấu hình, nó sẽ xuất hiện như một tùy chọn nguồn dữ liệu khi
cấu hình trường Dropdown (hoặc tương tự) trong tab **Xây dựng biểu mẫu**.

<Callout type="tip">
  Sử dụng Get API khi danh sách các lựa chọn hợp lệ được quản lý ở hệ thống bên ngoài và cần được
  đồng bộ tự động.
</Callout>

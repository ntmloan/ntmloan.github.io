---
title: After Flow
description: Configure automated actions that run after an application is fully approved
icon: Zap
---

The **After Flow** tab configures automated actions that Workflow triggers once an application
completes its entire approval route successfully.

Use After Flow to chain follow-up actions to an approved application (for example, additional
downstream workflow steps) without requiring manual setup each time.

<Callout type="info">
  After Flow actions only run after an application reaches a fully **Approved** state — they do
  not run for Denied, Canceled, or Sent Back applications.
</Callout>

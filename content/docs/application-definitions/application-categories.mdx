title: Application Categories

---

Application Categories organize **Application Definitions** into groups (for example, by
department or request type), used when browsing or creating a new application.

Categories can be created inline while configuring an Application Definition, or managed directly
from this page.

<Callout type="info">Only Company Admins can manage Application Categories.</Callout>

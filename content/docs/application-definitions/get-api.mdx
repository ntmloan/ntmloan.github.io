---
title: Get API
description: Connect external data sources to populate dropdown and lookup fields
icon: Plug
---

The **Get API** tab configures an external "resource" API whose data can populate dropdown or
lookup fields in the Form tab — for example, pulling a list of values from another system instead
of maintaining them manually inside Workflow.

Once a Get API resource is configured, it becomes available as a data source option when
configuring a Dropdown (or similar) field in the **Form Builder** tab.

<Callout type="tip">
  Use Get API when the list of valid options is maintained in an external system and should stay
  in sync automatically.
</Callout>
